# 多品牌真实色号 · 实施方案

> 目标：让图纸输出**真实品牌色号**（MARD / Artkal / Hama / Perler 等），并支持换品牌。
> 本方案只做规划，代码未改。文中数字均来自本机实测与已下载数据。

---

## 一、三个勘探结论（先看这个）

### 1. 项目里那份「5 品牌色板」是假的，而且根本没被用

`utils/palette.js` 里确实躺着 Perler / Hama / Artkal / Pyssla / Mard 五组色，但：

| 问题 | 证据 |
|---|---|
| 色号是编的 | `P01` / `H01` / `A01` / `Y01` / `M01` 是顺序编号，不是品牌真实色号 |
| 色值是近似值 | 文件头注释自称「颜色值为近似 HEX，正式量产前请以实物色卡为准」 |
| **完全没被使用** | `paletteLoader.js:34` 是唯一色板来源，只读 `data/colorPalette.js`（C01–C56 通用色） |
| 主流程没接 | 全项目搜 `brand`：只有 `app.js:11` 一个 `prefs.brand` 字段和色号选择页的展示，量化/导出链路都没用上 |

**结论**：不是「往色板里加几个颜色」，而是要真正接一套品牌色板体系。

### 2. 真实数据拿得到（已下载核实）

社区维护色卡库 [maxcleme/beadcolors](https://github.com/maxcleme/beadcolors)，`raw/` 下 15 个 CSV，
格式 `[色号, 名称, R, G, B, 贡献者]`，**合计 2093 色**。已实际下载并解析，数据干净可用。

### 3. 性能不是阻碍（实测数据）

映射环节耗时（240×240 = 57600 像素，Node 环境）：

| 色板 | 色数 | 现状写法 | 加颜色缓存后 |
|---|---|---|---|
| 现有通用色 | 56 | 20 ms | 11 ms |
| Hama | 92 | 28 ms | — |
| Artkal C | 174 | 54 ms | — |
| **MARD** | **291** | **91 ms** | **33 ms** |

加缓存后，**291 色（33ms）比现在 56 色的现状（91ms）还快 2.8 倍**。

顺带查出两个性能隐患（现在色板小，被掩盖了）：

- `utils/bead.js:57-60` — `nearestPalette` 用 `indexOf` 线性查下标，单像素 O(色板大小)
- `utils/mapToPalette.js:46` — **每个像素**都 `new` 一个 `filter` 数组，色板一大就是 GC 灾难

缓存版顺手解决这两处。

## 三、方案

### 1. 数据层 —— 可复现，不手抄

- 新增 `tools/gen_brands.py`：从 CSV 生成 `data/brands.js`
- 结构：`{ key, name, size, colors: [{ code, name, hex }] }`
- 现有 `data/colorPalette.js` 保留为「通用色板」选项（老图纸兼容）

### 2. 接入层 + 性能

- `paletteLoader.getPaletteColors(brandKey)` 支持按品牌加载
- 加颜色缓存（`Map`，rgb → 下标）+ 预建彩色候选数组
- `app.globalData.prefs.brand` 真正生效，默认品牌改成 **MARD**（现在是 perler）

### 3. 应用层 —— 三个入口都跟随品牌

| 入口 | 变化 |
|---|---|
| 图片转图纸 | 量化时使用所选品牌色板 |
| 导出图纸 / 清单 / 打印 | 色号、用豆量按品牌输出 |
| **色号转换（新功能）** | 已有图纸一键换品牌：图案配色不变，只把每个色号就近映射到目标品牌 |

「色号转换」是关键：用户用 MARD 做的图纸，能直接换成 Hama 色号去买豆子。

### 4. 兼容

- 老图纸存的是 C01–C56 色号 + hex：**按 hex 还原**，不会因为换色板而变色
- 图纸记录新增 `brand` 字段；换品牌时提示「色号将按目标品牌重新标注」

### 5. 验证

- 数据完整性断言（色号唯一、hex 合法、无重复）
- 算法回归（`editor_extract_test` 20/20）
- **性能基准固化脚本**（把上面那张表变成测试，防以后色板变大又悄悄变慢）
- 渲染对比图（同一张图在 MARD / Hama 下的实际效果）

## 四、两点必须说清

1. **色值不是官方值。** Hama / Perler / Artkal 官方都没公开 hex，这批数据是社区从实物拍照取色整理的，**和实物一定有色差**。
   建议关键颜色拿手上的豆子校一遍，可以留一个「校色」入口让你改 hex。

2. **Perler 色号印不进格子。** 它是 `80-15179` 这种长 SKU。
   需要定短码规则，建议：格子内印末 4 位，图例写完整色号。
