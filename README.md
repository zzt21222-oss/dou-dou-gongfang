# 豆豆工坊 A · 拼豆图纸生成小程序

这是一个把照片转换成「能照着拼」的拼豆施工图的微信小程序。核心功能在小程序端本地完成，使用者不接后端也能走完整流程。云开发相关能力预留了接入位，未开通时程序会自动退回本地存储。

## 功能

- **导入与预处理**：支持相册或拍照导入，支持调节亮度、对比度、饱和度，支持旋转、镜像、按比例裁剪、笔刷抠图与去白底。
- **像素化与降色**：底板可设 1–200 粒，形状支持矩形、圆形、六边形；颜色数可设 2–60；提供均匀量化、中位切分、K 均值、主色调四种降色算法。
- **品牌色板**：内置 Perler、Hama、Artkal、Pyssla、Mard 五套色号。使用者可以锁定「只用手中已有的颜色」。网格对齐模块数识别用于避免二维码类图案缺块。
- **图纸编辑**：支持单点换色、连通区填充、画笔、橡皮擦，内置图形模板，实时统计色号、名称与粒数。
- **输出**：提供像素、符号、豆子实景三种预览；可生成带坐标编号、辅助线、图例与材料清单的 A4 打印图；可复制采购词、保存图纸到相册、写入历史记录并分享。
- **辅助能力**：试色器可拍照识别主色并匹配最近色号；使用说明页提供大字体与高对比无障碍开关。
- **云开发**：`cloudfunctions/imgSecCheck` 负责图片内容安全检测，`cloudfunctions/syncHistory` 负责历史记录跨设备同步，两者均带本地兜底。

## 本地运行

1. 安装「微信开发者工具」，选择「导入项目」，把目录指向本仓库根目录。
2. 打开 `project.config.json`，把 `appid` 的占位值 `YOUR_APPID_HERE` 改成你自己的小程序 AppID；也可以在开发者工具里选择「测试号」。
3. 基础库选择 3.0.0 或更高版本，编译后即可在模拟器中使用。

仓库里的 `appid` 是占位值，不是可用的小程序号。本仓库不包含任何密钥或云端凭证。

## 目录

| 路径 | 内容 |
| --- | --- |
| `pages/` | 7 个页面：制作、参数调整、图纸编辑、预览、历史、使用说明、试色器 |
| `utils/` | 降色、色板映射、渲染、存储、模板、云同步封装等核心逻辑 |
| `data/` | 品牌与色板数据 |
| `cloudfunctions/` | 两个云函数：图片安全检测、历史同步 |
| `tools/beadcolors/` | 五个品牌的原始色号表，生成脚本位于 `tools/gen_brands.py` |
| `verification/` | 离线回归脚本与测试素材 |
| `overview.md`、`RUN.md` | 功能清单与运行说明 |
| `docs/` | 多品牌色号方案说明 |

## 验证脚本

`verification/run_all.sh` 依次运行 13 组离线检查，覆盖静态检查、存储、渲染、色号、模块识别与多轮回归。运行前需要 Node.js。第 6–13 组依赖 `@napi-rs/canvas`，使用者需要安装该模块，并把 `NODE_PATH` 指向包含它的 `node_modules` 目录。缺少依赖时脚本会列出跳过项并判定失败，不会静默通过。运行结果以本机实际执行为准，本仓库不附带运行结果。
